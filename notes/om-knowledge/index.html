記住呢句

1. 系統地圖（你行場要有張腦圖）

記住呢句

受控／潔淨送風空間＝風（潔淨＋壓差）＋水（冷凍）＋火（滅火＋聯鎖）＋電（不停電分層）＋醫氣＋監控；任何一環壞都會拖第二環。

點解

氣流方向靠壓差同風量差；關鍵負荷靠電；滅火方式要配合房間用途同設備；醫用氣體係受規管生命支持；CCMS 係你最早收到警報嘅地方。一環異常會連鎖：例如過濾塞 → 風量跌 → 壓差掉；泵停 → 盤管唔冷 → 有人亂加風量 → 壓差再亂。

2. 空氣側（MVAC）

2.1 AHU（Air Handling Unit／空氣處理機組）——全日鮮風嘅核心

記住呢句

受控／潔淨送風空間常用全日新鮮空氣 AHU：過濾 → 冷卻／加熱 → 送風；唔靠大量循環風「慳冷」去換潔淨級。

點解
  • 空氣處理順序：室外鮮風先經過濾；再經冷卻盤管——空氣被冷卻，同時相對濕度上升、多餘水汽可能凝結排出（去濕）；若房要定溫定濕，後面常有再熱／加濕步驟。全日鮮風＝幾乎唔混室內回風，所以每次都要重新冷卻／加熱，能耗同過濾負擔都高。
  • 點解少用大量循環：工作區要控制微粒、氣味同廢氣方向；循環風會把房間內污染物再送返入工作區。潔淨／氣流方向優先於「慳冷」。
  • 過濾差壓 vs 風機曲線（定性）：濾網髒 → 阻力↑ → 同一風機轉速下風量↓。差壓高唔等於「風機壞」，多數係濾阻；但風量跌會直接拖低房間送風，間接令壓差唔穩。
  • 旁通縫風險：機組門、濾框墊片、旁通風門若關唔實，未過濾空氣會「偷入」送風側。
保養／巡查睇咩
  • 機組門關好、密封條完整；冷凝水盤去水暢通、無積水發霉
  • 各級過濾差壓／更換紀錄；有無旁通縫
  • 盤管翅片髒唔髒、冷凍水閥動作、送風機軸承／皮帶／變頻狀態
  • 凍水／熱水管有無滲漏喺 AHU 房（地面水跡＝紅旗）
  • O&M：濾網規格、更換週期、清潔程序——跟手冊，唔估
教學對位

服務受控區嘅 AHU 屬全日鮮風路線；AHU 房可能擴建／插入既有機組之間——施工同保養都要分清邊部機服務邊區。

Warn

開機門做檢查要停機／上鎖掛牌（跟場規）；運轉中伸手入風機＝嚴重安全事故。

2.2 過濾同 HEPA

記住呢句

粗／中效保護盤管同風機；HEPA（High-Efficiency Particulate Air／高效微粒過濾）主要管潔淨，多數裝喺末端送／回風口；壓差唔係靠 HEPA「塞住」造出嚟。

點解
  • 分層意圖：機組內粗／中效＝護盤管同風機葉輪；末端 HEPA＝護房間潔淨級。
  • MPPS（一句）：HEPA 最難攔嘅粒徑大約喺「最易穿透粒徑」（MPPS）附近。
  • 完整性測試（概念）：換 HEPA 後要用規定方法查外殼／墊片有無洩漏旁通；唔係 DIY 拿手電照一下。
  • ΔP vs 潔淨意圖：設計意圖係「風量差造壓，過濾造潔淨」，唔係靠濾網當塞子造正壓。
保養／巡查睇咩
  • 過濾級順序有冇裝錯、有冇漏裝墊片
  • HEPA 有無旁通、外殼變形、更換同完整性測試程序
  • 差壓計／開關係咪合理；「差壓高」＝該換定係風量異常，要分開想
  • 更換時保護下游潔淨——跟潔淨規程同 O&M，唔貪快
教學對位

受控房末端送回風口路線常有 HEPA；巡查時分清「機組內過濾」同「末端 HEPA」兩層。教學以末端送風 HEPA 為主；回風有無 HEPA 跟獲批圖。

Escalate

未做完整性測試就當「已經 HEPA 合格」——唔可以。

2.3 風管、風閘、MSFD（機械煙火閘）

記住呢句

風管係氣流嘅路；調風閘調風量，防火／防煙閘（含 MSFD：Motorised Smoke Fire Damper／電動防煙防火閘）喺火警時切斷蔓延——兩者用途唔好混。

點解

調風閘卡住→房間風量同壓差錯；防火閘誤關或未聯鎖→火災時煙火經風管走，或者日常無故斷風。氣體滅火放電時，風機停同 MSFD 關係一條時間序列：關得太慢＝氣體流失；亂試聯鎖＝可能誤停送風令受控區失壓。

保養／巡查睇咩
  • 軟接有無破裂漏風；保溫完整（冷凝＝漏冷＋發霉風險）
  • 防火閘：釋放機構、位置指示、聯鎖測試紀錄
  • 施工後有無雜物留喺風管；天花開孔補回
  • 標籤：邊條管去邊間房——對唔到就唔好盲調
教學對位

受控區風管改動多、同既有系統交接；氣體滅火放電時風機／防火閘要按序列關——識「存在」，唔好現場亂試。

Warn

唔好手動卡住防火閘「方便送風」；火警時係責任問題。

2.4 CAV vs VAV

記住呢句

CAV（Constant Air Volume／定風量）＝送（或抽）風量大致定死；VAV（Variable Air Volume／變風量）＝風量隨負荷變。受控／潔淨壓差 cascade 多數用 CAV。

點解
  • CAV：控制器量測風量，驅動風閥／變頻貼近設定。溫度多用盤管水閥或再熱調焓，風量保持穩，壓差先穩得住。
  • VAV：溫感要求多冷／少冷 → 風閥開大／關細 → 風量變。每間房風量一變，相鄰房之間嘅壓差就跟住抖。
  • 點解 ΔP cascade 偏愛定風量：壓差靠「每間房送−抽 ≈ 設計洩漏」。風量若隨負荷飄，洩漏同方向都會飄。
  • 唔係「VAV 高級、CAV 落伍」——係用途唔同。
保養／巡查睇咩
  • 對圖確認箱體類型（CAV／VAV）、設定風量、執行器同位置反饋
  • CAV：設定值被改過未？風閥有無卡死全開／全關？
  • VAV（若周邊有）：最低風量設定夠唔夠維持通風同壓差意圖？
  • Setback／夜間模式改嘅係邊幾個 box——對邏輯表
教學對位

受控房壓差故事建喺 CAV＋壓差穩定器；你識 VAV 係為咗答「點解唔用」、同理解大樓其他區可能唔同。

2.5 房間壓差同 pressure stabiliser

記住呢句

送風多過離開房間嘅風 → 正壓；空氣由高壓（較乾淨）流向低壓（較污）。Pressure stabiliser（壓差穩定器）幫你喺門關時把壓差鎖近設計值。

點解
  • 質量平衡：Qs − Qe ≈ Qleak。多出嚟嘅風經門縫、傳遞窗、穩定器等路徑離開。
  • 開門暫態：門一開壓差會垮一截；量度同驗收多數以門關為準。
  • 穩定器＝受控洩漏：設計好嘅洩壓路徑，唔係「門封膠條神話」。封住穩定器＝改咗設計洩漏。
  • Cascade 方向：高要求房（最高正壓）→ 緩衝／前室 → 走廊（較低）。具體 Pa 數見獲批圖。
保養／巡查睇咩
  • 門關測壓差；門底縫、傳遞窗、天花開口有無額外大漏
  • 穩定器裝向、有無堵塞、有無被人膠帶封住
  • 相鄰房同時開門會唔會互相拖壓差——觀察、記錄
  • 壓差錶／傳感器校正同安裝位置
教學對位

典型 cascade 概念：高要求房最高正壓 → 緩衝／前室次之 → 走廊／dirty 側更低（具體 Pa 數見獲批圖）。

Escalate

高要求房門開會唔會拖低相鄰受控房——文件未寫死就要問清楚，唔好自己當冇事。

2.6 Normal vs Setback——ACH 同 ΔP 係兩件事

記住呢句

Setback＝慳風／慳能模式；通常仍要維持壓差方向同溫濕大致受控，但全速換氣次數（ACH）唔維持。

點解
  • ACH 講「一小時換幾多次氣」；ΔP 講「邊間高邊間低」。Setback 可以減 ACH，但仍應維持 cascade 方向，唔可以反轉。
  • 唔好用 Normal 嘅 ACH 去判 setback 失敗——要查方向有冇反、溫濕有冇越限、邊個 box 被關錯。
保養／巡查睇咩
  • 邊啲 CAV／風機喺 setback 關或減——對控制邏輯
  • 轉換 Normal↔Setback 有無警報、有無溫濕／壓差越限
  • 人手覆寫（manual override）有冇人忘記复回
教學對位

受控區有 Normal／Setback 控制意圖；細節風量同邊個 box 關——對 AHU／CAV 附錄同獲批圖。

2.7 主備風機（Duty／Standby）切換

記住呢句

主機壞／跳脫 → 備機自動或按程序頂上；切換瞬間風量同壓差會抖——要識睇警報同恢復。

點解
  • 受控區常要連續送風；單風機無備＝單點故障。
  • 常見故障：備機未真正起動；風閥互鎖卡中間；CCMS 顯示已切但現場仍係舊機；切換後未回穩就被當完成。
  • 切換瞬間風量短暫跌 → 壓差抖——屬預期暫態；要睇有冇喺時限內恢復。
保養／巡查睇咩
  • Duty／Standby 狀態燈同 CCMS 一唔一致
  • 定期切換測試有無做、有無卡閥
  • 切換後過濾差壓、房壓、噪音有無異常
  • 手動強迫切換要有 PTW（Permit to Work／准工證）／場規
教學對位

相關風機有主備同 CCMS 警報意圖——巡查先睇畫面再入場。

Warn

運轉中亂切、或者關掉唯一運行風機「聽吓靜唔靜」——可以令受控區失壓。

3. 水側（冷凍水／盤管／泵）

3.1 風冷冷水機（Air-cooled chiller）

記住呢句

風冷機＝室外用風扇帶走冷凝熱，製造冷凍水畀 AHU 盤管；冇冷卻水塔，但室外盤管髒同氣流受阻一樣會冇冷。

點解
  1. 壓縮機把低壓冷媒蒸氣壓成高溫高壓氣；
  2. 冷凝器（室外盤管）用室外風帶走熱，冷媒冷凝成液；
  3. 膨脹裝置降壓，液冷媒變低溫低壓；
  4. 蒸發器入面冷凍水把熱傳畀冷媒，水變凍——再入壓縮機。

氣流短路：室外排熱若被牆／鄰機擋返吸入冷凝器，等於「吸自己嘅熱風」——冷凝壓力升、效率跌、甚至高壓跳脫。

保養／巡查睇咩
  • 室外盤管清潔、風扇運轉、異響、結霜／結冰異常
  • 冷凍水供／回水溫差是否合理（跟設計意圖同當下負荷）
  • 制冷劑壓力／報警歷史（合資格人）；你主要識「有警報要升級」
  • 底座、減震、排水、電氣盤受潮
教學對位

風冷冷水機服務本區冷凍需求；接既有冷凍水總管／header——施工期 tee-off 同日常洩漏都要盯。

Escalate

制冷劑操作屬受規管工種——唔識唔做。

3.2 冷凍水回路、水泵、AHU 盤管

記住呢句

冷量係「水運」去盤管；泵提供流量，閥調節，盤管先換到熱——有冷機但泵停／閥關＝房一樣熱。

點解
  • 容量 ≈ 流量 × ΔT × 常數。流量不足或 ΔT 異常＝盤管換唔到設計冷量。
  • 常見故障鏈：Y-strainer 塞 → 流量↓ → 盤管唔冷 → 房溫高 → 有人狂開 CAV 風量「補救」→ 壓差亂。
  • 盤管氣阻：水系統入氣會佔住水路；要按程序排氣。
  • 閥同旁通：控制閥卡關／旁通常開 → 水唔經盤管或短路回流。
保養／巡查睇咩
  • 泵：聲、震、軸封滲漏、壓力錶、变频器故障碼
  • 過濾器／Y-strainer 前後壓差；排污有無做
  • 盤管：進出水溫、水閥行程、盤管氣阻、冷凝水排水
  • 閥門標籤同開關狀態；旁通閥有無人常開
  • 保溫破損→結露滴水→天花霉同電氣風險
教學對位

AHU 靠冷凍水盤管造冷；水側異常會直接反映喺受控房溫濕同「為咗追溫度亂調風」。

Warn

帶壓系統排污／拆法蘭要跟程序；燙／凍水都可以傷人。

3.3 防凍、洩漏、水質

記住呢句

冬天盤管凍裂同日常滲漏一樣可以停晒受控區服務；水質差→結垢／腐蝕→流量同換熱雙輸。

點解
  • 凍裂：盤管內水溫過低 → 水結冰體積脹 → 銅管／接頭裂。
  • 洩漏早期徵兆：補水頻率異常、盤面／接頭水跡、天花水漬。
  • 水質：結垢加熱阻、腐蝕出鏽渣再塞 strainer。
保養／巡查睇咩
  • 低溫警報同防凍設定有無人亂改
  • 水系統補水頻率異常＝可能洩漏
  • 水質化驗／加藥紀錄（跟場內水務／O&M）
  • 施工 tee-off／熱燙接後：焊口、法蘭、支架——特別係天花板上
教學對位

有冷凍水接駁同可能嘅管道凍結保護措施意圖——對獲批圖同方法陳述，唔靠猜想。

4. 消防

4.1 濕式花灑 vs Pre-action

記住呢句

濕式＝管內長期有水，熱玻璃膽爆就出水；Pre-action＝平時管內多數係氣／乾，要滿足啟動條件先入水／出水——減少誤射水摧毀受控空間同設備。

點解
  • 濕式＝水已喺管到噴頭底下，反應快但誤開／凍裂／撞擊都可能出水。
  • Pre-action＝平時乾或監管氣壓，要探測／聯鎖先開閥入水——用「多一步」換誤射風險下降。
  • 代價：氣壓監管、電磁閥、探測、信號都要健康；低氣壓警報＝大事。
保養／巡查睇咩
  • 閥組位置、鎖固、標牌、旁通狀態
  • 氣壓／監管信號正常；低氣壓警報要當大事
  • 探測器污染（裝修塵）→誤報風險
  • 週期測試同排水——跟消防規程／場內程序同合資格承辦
教學對位

高敏感受控區走 pre-action 路線；支援區可能仍係濕式——分區唔好當全部一樣。

4.2 Double interlock（雙連鎖）

記住呢句

Double interlock＝要兩類獨立條件齊（例如探測＋另一聯鎖信號／釋放步驟，以獲批圖同產品說明為準）先進入出水序列——再減誤射。

點解
  • 單連鎖已經比濕式嚴；雙連鎖要求兩條獨立腿都真——邏輯上係 AND，唔係 OR。
  • 風險：誤調／短接其中一條輸入 → 畫面可能仲顯示「有保護」，實際未成連鎖。
保養／巡查睇咩
  • 啟動序列寫喺邊、有無修訂
  • 測試時確認兩條腿都真係要；唔好為「方便」短接信號
  • 施工後恢復：臨時短接／inhibit 有冇清走
教學對位

設計意圖常係雙連鎖 pre-action——常考「點解唔用普通花灑」。

Warn

禁止為趕工期永久短接消防信號。

4.3 氣體滅火（Novec 類）

記住呢句

電氣房／UPS 房常用潔淨氣體滅火（例如 Novec 類）——唔靠浸水；放電前要走人、關風機／防火閘，避免氣體流失同人員危險。

點解
  • 水會毀電池同電力電子；潔淨氣體靠降低氧／吸熱（視介質）滅火。
  • Hold time同圍封完整性：門縫大、風管未關、洩壓口錯 → 氣體走光＝滅火失敗。
  • 序列概念：警報 → 疏散延時 → 停相關送／排風 → 關防火閘 → 放氣。
保養／巡查睇咩
  • 鋼瓶壓力／重量檢查紀錄、噴嘴無堵塞、管路完整
  • 手動／自動模式、inhibit／isolation 狀態要清晰
  • 門密封、洩壓口、聯鎖風機同 MSFD
  • 人員警報、延時、疏散路線——識程序，唔現場試放
教學對位

UPS／電池房走氣體滅火意圖；同受控區花灑系分家——唔好當成同一套閥。

Escalate

任何「試放／洩放」只可以由授權人按程序做。

4.4 MSFD／煙感聯鎖同施工期臨時消防

記住呢句

火警時：停相關風機、關防火閘、放氣體或啟動水系統——聯鎖係一條鏈；施工期主系統暫停就要有臨時探測＋看守＋PTW。

點解

裝修塵觸發煙感、切斷消防幹管、封路——營運中場地最怕「空窗」。臨時措施唔係可有可無；恢復時若漏撤 inhibit，等於長期假保護。

保養／巡查睇咩
  • 聯鎖矩陣：邊個探測觸發邊啲閘／風機
  • 臨時煙感電池、覆蓋範圍、值班紀錄
  • 恢復時：臨時措施撤銷清單、主系統复位測試
  • 通道、消火栓、滅火筒受阻？
教學對位

營運中場地改建——噪音塵同消防暫停都要同設施管理協調；溫習時要識問「而家靠臨時定主系統」。

5. 電力

5.1 Normal／Essential／UPS 分層——Ride-through

記住呢句

Normal＝市電日常；Essential＝市電失電後由發電機等應急來源撐嘅重要負荷；UPS（Uninterruptible Power Supply／不間斷電源）＝切換空檔都唔俾斷嘅「唔間斷」段（電池＋逆變）。

點解
  1. 正常：負荷由市電（Normal）供；
  2. 市電失電：ATS（Automatic Transfer Switch／自動轉換開關）／發電機起動需要時間——Essential 路徑可能仲未到；
  3. UPS 橋接：電池經逆變器即時頂住「唔可以斷」嘅負荷；
  4. 之後：發電機／Essential 就緒後持續供電；UPS 電池再充電待命。

電池自主時間：設計會訂「撐幾耐」——實際分鐘數跟獲批圖／O&M，唔背假數。

保養／巡查睇咩
  • 單線圖：邊啲負荷掛 Normal／Essential／UPS——標籤同現實一致？
  • 電池：室溫、端子、警報、自主測試紀錄（合資格人）
  • 發電機測試同 ATS／轉換開關紀錄（場級）
  • 插座同回路有冇被人私自改掛「當 UPS」
教學對位

受控區有 Essential 同 UPS 分層意圖；容量同斷路器額定以獲批圖同相關文件為準。

Warn

營運中場地帶電操作要 PTW；唔好當「只係睇吓」就開電蓋。

5.2 STS／Bypass 概念

記住呢句

STS（Static Transfer Switch）＝兩路電源之間快速自動切；Bypass＝維修時讓負荷暫時繞過 UPS 電子路徑——方便維修，但期間保護等級可能下降。

點解
  • STS：兩路之間以靜態開關極快切換；要求兩邊電源質素／相位條件符合。
  • Maintenance bypass 風險：若有人做完留喺 bypass「貪方便」＝以為有 UPS 其實冇。面板指示 Normal／Battery／Bypass／Fault 要當巡查必睇項。
保養／巡查睇咩
  • 面板指示：Normal／Battery／Bypass／Fault
  • 維修後有冇退出 bypass
  • 雙電源相位／同步條件（概念上要知「唔係隨便兩插座」）
  • 警報有冇塞靜音後唔跟進
教學對位

UPS 系統維修同切換要按 O&M；溫習識名同風險，實作交合資格電工。

5.3 巡查與切換（PTW／營運中場地）

記住呢句

任何影響受控區電力嘅切換＝計劃工作：時段、通知、後備、回退、誰可以喊停。

點解

冇協調嘅「試跳」可以停關鍵服務。紙面 PTW 同真正溝通缺一不可。回退計劃＝「切唔成點返原狀」。

保養／巡查睇咩
  • 工作前：負荷清單、受影響房、通訊方式
  • 工作中：有人盯關鍵警報同使用單位聯絡
  • 工作後：確認負荷回正確來源、bypass 清除、紀錄完整

6. 醫用氣體系統（通用）

記住呢句

醫用氣體係受規管生命支持系統：總管分接 → AVSU（Area Valve Service Unit／區域隔離閥箱） → 房間終端；區警報係你嘅早期警告——唔教你親手焊／亂關閥。常見氣體品種包括氧氣（O2）、真空（Vacuum）、醫療空氣（如 MA4）等——以獲批圖為準。

點解
  • 身份防錯接：終端用銷釘指數（pin index）／顏色／形狀編碼。
  • AVSU＝區域隔離：一區有事可以關該區閥，唔使即斷全棟。關錯服務中受控區嘅 AVSU＝緊急事態。
  • 警報層級：區警報／總警報分層提示壓力異常；消音只係暫時靜音。
保養／巡查睇咩
  • AVSU：標籤、開關狀態、通道唔阻塞、玻璃／鎖完好
  • 區警報：面板位置、消音後有冇跟進、測試紀錄
  • 終端：顏色／形狀防錯接、有無漏氣聲、保護膠蓋
  • 工程改動後：邊類測試要做（壓力、純度、交叉連接等）——概念上知有測試鏈
教學對位

由既有 riser tee-off 入受控區；氣體品種同終端以獲批圖為準。

Warn

唔准當普通壓縮空氣管路去「試噴」；唔准私下關閉服務中受控區嘅 AVSU。

Escalate

任何氣味／壓力驟降／警報 → 即時按場內應急同工程程序，唔自行診斷完先報。

7. 監控 CCMS（Central Control and Monitoring System／中央監控系統）

記住呢句

CCMS 係耳目：警報、狀態、趨勢；唔係俾你隨便當遊戲改控制參數。

點解
  • 鏈路：傳感器 → 控制器／DDC（Direct Digital Control／直接數位控制）→ 畫面＋警報 → 人去現場確認。
  • 趨勢 vs 即時快照：單一即時值容易被暫態騙；趨勢圖先睇得出「慢慢漂」定「突然垮」。
  • 改 set-point＝改設計意圖——要授權、紀錄、可回退。
保養／巡查睇咩
  • 每日：優先級警報清唔清、有冇長期 acknowledg 未修
  • 趨勢：房溫／壓差／差壓——突變先於投訴
  • 點位名同現場標籤一致；「壞點」要標咗壞
  • 改參數：授權、紀錄、回退——無授權唔改
教學對位

風機切換、壓差、主要設備狀態有監控意圖——巡查建議「先畫面、後現場」。

Warn

無授權唔好改 iBMS／CCMS 程式或 set-point。

8. 保養巡查思維（可執行清單）

記住呢句

巡查係固定節奏＋異常升級；唔係等到壞先學問。

8.1 每日（或每更）——快、可重複

  • CCMS／警報面板：火警監管、壓差、AHU／泵、UPS——有新增未清？
  • 受控房：門關壓差觀感／錶讀（跟場規頻率）；門有無長期打開
  • AHU 房：異響、水跡、焦味、門關好
  • 醫氣區警報：正常抑或靜音中
  • 走火通道、臨時工程範圍：消防器材受阻？

8.2 每週——稍深入

  • 過濾差壓趨勢；該換未換
  • Duty／Standby 狀態同上次自動／手動切換紀錄
  • 泵區：滲漏、震、壓力
  • 消防閥組目視：位置、鎖、標牌；氣壓（pre-action）
  • UPS／電池房：溫度、警報、通道；氣體滅火面板模式（有無留喺 bypass／inhibit）
  • 同使用單位／設施短會：有無「間中失壓／間中熱」投訴未立案

8.3 每季（或按 O&M／合約）——計劃性

  • 聯鎖同切換測試（消防／風機／電源）——合資格人＋PTW
  • HEPA／過濾更換同測試計劃進度
  • 水質／水系統保養節點
  • 校正：壓差錶、關鍵溫度／濕度傳感器
  • 文件：獲批圖修訂、O&M、警報設定有無過期
  • 演習：停電／失壓／氣體警報紙面走位（教學同場規）
保養／巡查睇咩

每項有「邊個做、紀錄去邊、超標點升級」——無主責＝假清單。

教學對位

改建期同營運期清單側重唔同，但升級紀律一樣。

9. 常見故障聯想（教學推理，非現場定案）

記住呢句

先畫因果鏈再動手；見到 A 唔等於只修 A。

9.1 空氣／壓差

見到先問常見方向（教學）
一間房正壓掉門開？穩定器堵？抽風過大？送風不足？相鄰房？查門同風量差，唔先拆 HEPA；開門暫態要同門關讀數分開
兩間房互相拖門同時開？共用走廊洩漏？記錄操作模式；cascade 方向可能被大洩漏短路
全層風細AHU 跳？過濾塞爆？防火閘誤關？先機組同聯鎖狀態；濾阻↑沿風機曲線風量↓
房溫高但壓差仲喺水側／盤管／閥唔好靠加大風量「硬搶冷」——會破壞已穩嘅 ΔP
切換風機後壓差抖完唔返備機真起動？風閥互鎖？對 CCMS 同現場狀態燈；暫態過後仍低＝未完成切換

9.2 水側

見到先問常見方向（教學）
有機無冷泵？閥？冷機警報？盤管氣阻？跟水溫 ΔT 同流量；strainer 塞→流量↓係常見源頭
天花滴水保溫？盤管排水？管道滲？分冷凝（保溫破）同眞漏（補水頻密）
泵又震又響氣蝕？對中？軸承？底座？停機檢查屬授權工作；氣蝕常同吸程／過濾塞有關
室外機高壓跳盤管髒？氣流短路？排熱被吸返＝冷凝差；先環境同清潔

9.3 警報／監控

見到先問常見方向（教學）
警報風暴裝修塵？眞火？電源閃？先生命安全，再分類；塵觸煙感係營運中場地常見
長期靜音邊個消音？根因未除？當未解決故障；靜音≠正常
畫面正常現場唔正常傳感器壞／裝錯位？以安全側現場為準並升級；趨勢可證「假正常」
UPS 以為有其實無面板係咪 Bypass？維修後留 bypass＝ride-through 斷咗
教學對位

受控區最痛通常係失壓／誤水／失電三條線——任何一條都要短時間內升級到有權決定嘅人。
